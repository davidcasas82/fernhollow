# Chiptune previews

Original music and effects for Fernhollow, written as note data and synthesized in the game. These files are for listening. The game still plays Neon Swarm until `FERN_CHIPTUNE` in `js/constants.js` is turned on.

| File | What |
|------|------|
| `title-heroic.mp3` | Title. Heroic and bright. One full loop. |
| `courtyard-battle.mp3` | Courtyard battle. The bass line leads. One full loop. |
| `boss.mp3` | Boss. Heavier and faster. One full loop. |
| `sfx-reel.mp3` | Swing, hit, foe pop, pickup, level-up, menu move, menu select, hurt, and the boss intro. The set plays twice. Quieter than the songs. |

Rebuild from the score with `node tools/render-fern-previews.mjs`.
