# Impact

A hit is a white flash, a short shove, a small shake, and a poof from the effects sheet. Score numbers use the pixel font. The end card uses that same plain lettering.

| File | What |
|------|------|
| `hit.png` | Courtyard during a hit. No comic word, starburst, or speech bubble. |
| `hit-close.png` | The same hit, cropped to the poof. |
